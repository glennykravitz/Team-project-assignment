DBT 1305 Web Application Development, Week 7 team project.

A seven-page website for a youth savings and lending group in Nairobi: Home, About, Savings, Loans, Events, Join and Contact. Every page shares the same header, navigation, notices and footer, and all styling comes from a single file, css/style.css.

Layout: The page is a CSS Grid with five named areas (header, nav, main, aside, footer). The navigation is a sticky Flexbox row, and the cards wrap onto new lines as the window narrows. One media query at the bottom of the stylesheet turns the page into a single column at 700 px and under.

House style: Four colours (teal, navy, coral and cream) and two typefaces (Fraunces for headings, DM Sans for text).

Checks: All pages pass the Nu HTML validator, use no inline styles, and don’t scroll sideways at any width from 360 px up.
